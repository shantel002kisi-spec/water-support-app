# Portfolio and competition package

## Short description

Water Support Without Barriers is a customer-support organiser with real on-device OCR, reviewable actions, persistent notes, a monthly calendar, editable support-request drafts, case checklists and conversation histories. It needs no API key or paid service. Water-provider lookup demonstrates fictional records.

## 90-second demo

1. Explain the problem: correspondence can be difficult to read, remember and act on.
2. Show the action/waiting/completed dashboard.
3. Scan the sample using real OCR, expand source text and correct a suggestion.
4. Confirm the deadline and save.
5. Add notes, export to calendar and mark complete.
6. Refresh, then search for the completed action.
7. Explain the boundary: the organiser works; provider integration is fictional.

For a longer demo, open Support centre, prepare a billing enquiry, save its case, record a phone conversation and an agreed check-in date, then show the updated calendar and export the case record. Demonstrate larger text and reduced-motion controls in Display.
